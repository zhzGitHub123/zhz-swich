# 安全与隐私

## 原则

- 本地优先。
- 最小收集。
- 明确授权。
- 敏感信息默认脱敏。

## 数据范围

应用只保存完成切换所需的数据：

- 档案名称。
- 目标应用。
- 订阅地址引用。
- 备注。
- 最近切换结果。
- 有限数量的备份记录。

不保存：

- 用户账号密码。
- 完整网络请求历史。
- 远程分析数据。
- 设备指纹。
- 自动上传日志。

## 敏感信息处理

- 订阅地址可能包含令牌，按敏感数据处理。
- 明文订阅地址优先保存到 Keychain。
- 日志、错误、事件记录中只出现脱敏地址。
- 导出配置时必须提醒用户可能包含敏感信息。

## 文件写入安全

- 修改目标配置前必须备份。
- 备份失败时不继续写入。
- 写入后必须重新读取验证。
- 验证失败时保留错误，不伪装成功。

## 网络行为

- 默认不联网。
- 只有用户点击检查时才请求订阅地址。
- 网络检查必须有短超时。
- 不发送额外遥测参数。

## 权限策略

- 初期尽量不申请多余系统权限。
- 只访问用户明确选择或目标应用需要的配置路径。
- 如果启用沙盒，需要把配置文件访问设计为显式授权。

## 日志策略

- 默认保留最近少量事件。
- 日志不包含完整 URL。
- 日志用于本地排障，不自动上传。
- 提供清空日志入口。
