# 开发计划

## 阶段 0：文档与边界

- 明确产品范围和非目标。
- 明确性能与耗电预算。
- 明确 Codex 与 Claude 目标配置需要真实验证。
- 完成项目初始化文档。

## 阶段 1：工程骨架

- 创建原生 macOS Swift 工程。
- 设置最小应用入口。
- 建立基础目录：App、Domain、Infrastructure、UI、Tests。
- 配置 Debug 与 Release 构建。
- 加入基础单元测试。

## 阶段 2：领域模型与本地存储

- 实现 `SubscriptionProfile`、`TargetApp`、切换结果和错误模型。
- 实现本地档案 repository。
- 接入 Keychain 保存敏感 URL。
- 为读写、脱敏和迁移路径补测试。

## 阶段 3：目标适配器

- 验证 Codex 配置位置和写入方式。
- 验证 Claude 配置位置和写入方式。
- 实现目标适配器协议。
- 加入备份、写入、验证和回滚测试。

## 阶段 4：菜单栏与设置界面

- 实现菜单栏快速切换。
- 实现设置窗口的档案管理。
- 实现错误、空状态和最近结果展示。
- 补充键盘导航和基础可访问性。

## 阶段 5：性能验证与打包

- 使用 Instruments 验证空闲 CPU、内存和耗电。
- 检查启动时间和菜单响应。
- 清理不必要依赖。
- 完成签名、公证和发布说明。

## 每阶段完成标准

- 有可运行构建。
- 有最相关测试或手动验证记录。
- 没有未解释的静默失败。
- 文档与实现保持一致。
