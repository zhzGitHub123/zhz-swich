## 项目概述

本项目是一个MacOs桌面级原生swift应用

## 设计风格

> [!IMPORTANT]
>
>以 Liquid Glass 为绝对主导，所有卡片、按钮、侧边栏都用系统级或自定义 Liquid Glass 材质（多层、动态折射、适应环境光）。

- MacOS 原生设计规范
- Liquid Glass 2.0 流体玻璃
- 多层悬浮流体玻璃数据卡片
- Bento 网格不对称布局
- 3D 柔和柱状图表
- 软胶圆角按钮
- 细微扫描线纹理
- 柔和桌面环境光影
- Sonoma 空间毛玻璃
- 触觉软胶拟物
- GenAI 轻量化界面
- 半透明悬浮景深
- 柔焦长阴影
- 极淡胶片颗粒
- 光学折射高光
- 漫反射柔光

> [!TIP]
>
> Micro-animations & Fluid Interactions：按钮按下时的液态变形、卡片悬浮时的轻微浮动、图表数据变化时的柔和 Morphing 动画。
>
> **Spatial / Depth Hierarchy**：利用 visionOS 影响的**空间深度层级**（不同悬浮高度 + 景深模糊）。
>
> **Adaptive / GenAI 动态**：界面根据内容或 AI 智能调整玻璃透明度、色调、卡片布局（Light/Dark + 环境光自适应）。
>
> **Typography & Focus**：大号可变字体（SF Pro Variable）、高对比动态文本（根据背景玻璃自动调整颜色）。
>
> **Icon System**：使用 Liquid Glass 风格图标（带折射和轻微 3D）。
>
> **Subtle Noise**：保留极淡胶片颗粒，但做成**可开关**或极低强度，避免干扰。
>
> **Scanline / Texture**：可以保留，但只用在非关键区域（如背景或装饰），主内容区保持干净



### 模块 1：提供商管理 (Providers)

**用途**：管理不同 AI 工具的 API 配置

**功能需求**：
- 列表展示所有提供商（云卡片布局）
  - 显示：提供商名称、图标、应用类型、当前状态
  - 支持：搜索、筛选（按应用类型）、排序
- 快速切换活跃提供商（单击切换）
- 添加新提供商
  - 表单：名称、API Key、Base URL、自定义参数
  - 支持：预设模板库（5+）、一键填充
- 编辑现有提供商
- 删除提供商（带确认对话框）
- 提供商排序（拖拽）
- 从本地文件导入配置
- 导出配置到文件

### 模块 2：MCP 服务器管理 (MCP)
**用途**：管理模型上下文协议 (Model Context Protocol) 服务器

**功能需求**：
- 列表展示已安装 MCP 服务器
  - 显示：服务器名称、命令、启用状态、绑定的应用
- 按应用筛选（Claude、Codex、Gemini 等）
- 启用/禁用 MCP 服务器（切换开关）
- 添加新 MCP 服务器
  - 表单：名称、命令、参数、环境变量
- 编辑 MCP 配置
- 删除 MCP 服务器
- 从本地文件导入 MCP 配置
- 从各应用实时同步 MCP 配置（一键同步按钮）
- 显示 MCP 健康状态（✅ 正常 / ⚠️ 异常 / ❌ 离线）

### 模块 3：提示词管理 (Prompts)
**用途**：管理可复用的 AI 提示词预设

**功能需求**：
- 提示词库列表（表格或卡片）
  - 显示：名称、分类、预览（前 50 字）、应用类型、创建时间
- 搜索与筛选（按分类、应用、标签）
- 创建新提示词
  - 表单：名称、分类、内容（Markdown 编辑器）、应用适用范围
- 编辑提示词
- 删除提示词
- 启用/禁用提示词
- 导入提示词（Markdown 文件或 JSON）
- 导出提示词集合
- 预览提示词内容


### 模块 4：技能管理 (Skills)
**用途**：管理插件和扩展功能

**功能需求**：
- 已安装技能列表
  - 显示：技能名称、版本、仓库、应用兼容性、启用状态
  
- 发现新技能
  - 连接到技能库网站或默认仓库列表
  - 搜索技能
  - 显示评分、下载数、更新时间
  
- 安装技能（从 GitHub 仓库或 ZIP）

- 卸载技能（带数据备份提示）

- 更新技能

- 启用/禁用技能

- 查看技能详情（README、作者、许可证）

- 设置自定义技能仓库源

- 备份/恢复技能配置

  

### 模块 6：使用统计与成本跟踪 (Usage)
**用途**：追踪 API 使用情况和成本

**功能需求**：
- 统计面板（仪表板）
  - 总成本（今日/本周/本月）
  - 总 Token 数（输入 + 输出）
  - 总请求数
  - 平均单次成本
  
- 按维度统计图表
  - 按提供商分布（柱状图、饼图）
  - 按模型分布
  - 按应用分布
  - 按时间趋势（折线图）
  
- 请求日志表
  - 显示：时间、应用、提供商、模型、输入 Token、输出 Token、成本
  - 支持：搜索、筛选、排序、导出 CSV
  
- 价格配置管理
  - 编辑各提供商模型的单价
  - 导入价格配置
  
- 使用数据源管理
  - 选择数据来源（本地计算、API 查询）
  
  - 同步使用数据
  
    
  
  
  
  ### 模块 7：环境变量管理 (Environment)
  
  **用途**：管理系统环境变量（API 密钥、代理设置等）

**功能需求**：
- 环境变量列表
  - 显示：变量名、值（敏感值加密显示）、所属应用、优先级
- 添加/编辑环境变量
  - 支持：从 .env 文件批量导入
- 删除环境变量
- 导出环境变量（.env 格式或 JSON）
- 环境变量冲突检测
  - 提示重复定义或冲突的变量
  - 建议最优配置
- 变量预设模板
  - 提供常用的环境变量模板（HTTP_PROXY、API_KEY 等）
  
  ### 模块 8：系统设置 (Settings)
  **用途**：应用全局设置和偏好

**功能需求**：
- 通用设置
  - 语言选择（中英日等）
  - 主题（深色/浅色/自动）
  - 开机启动
  - 最小化到托盘
- 数据管理
  - 备份/恢复数据库
  - 清空缓存
  - 导出所有配置
  - 数据位置
- 关于页面
  - 应用版本
  - 更新检查
  - 许可证信息
  - 作者和贡献者
- 快捷键设置
